# 22 · 对外定位（MVP：单一客户）

> 当前版本只服务一类用户、只承诺一种交付。完整产品定义见 [docs/24-MVP.md](24-MVP.md)。
> 对外口径统一为**团队**（we / our team）；我们是做工具的团队，用户是个人创作者。
> 所有能力描述都来自已跑通的链路，不写未验证的承诺。

## 一、给谁用

**个人视频制作者 / 起号阶段创作者**：一个人做选题、出片、发布，没有剪辑、设计、
工程同事可依赖；在海外社交平台做计算机技术科普内容，需要稳定试选题、快速迭代；
预算敏感，不接受订阅费与私有化部署。

最怕的不是慢，是**做出来不好看却没人告诉他为什么**。

不为以下对象维护对外材料（能力仍在仓库，只是不承诺、不报价）：机构内容团队、
DevRel / 技术市场、教育课程团队、研究论文传播团队。

## 二、我们只把一件事做扎实

**不过 QA 闸不出片。**

一句话主题 → 规划硬闸 → 单文件 HTML → 逐帧 1080p 渲染 → 11 项像素级 QA
（`avg < 8 → exit 1`）→ BGM / 音效 / 旁白 → 合成 → 执行报告。

一个人做片没有第二双眼睛，就用可测数字代替：确定性渲染（同 `t` 同像素）、
可按秒局部重渲、失败也落报告、CI 回归夹具。其余能力不写「我们擅长」。

## 三、片型都有，但只有一条主链

8s 钩子片 / 11s 带旁白 / 23s 论文科普 / 50s 项目片 / 180s 深讲片**全部可用**，
因为起号阶段本来就要试不同形态。三条输入线共用 100% 后半程
（`render → qa → audio → compose → report`），片型只是输入源与长度差异，
不是三条产品线，也不各配一套交付承诺。

## 四、唯一交付方式：免费自托管

| | |
|---|---|
| 得到 | 完整开源仓库（MIT），本机跑完，无账号、无遥测、无服务器 |
| 花费 | ¥0；只可能花自己的模型 API 用量与算力，无订阅费、无 token 加价 |
| 前置 | Python 3.10+ / Node 20+ / 本机 Chrome / ffmpeg；不需要 GPU、不需要付费连接器 |
| 定制 | 有具体需求可在 GitHub Issues / Discussions 提，不设报价档、不排期、不承诺交付 |

**没有第二档、第三档**。Integration / Managed series / 发现会报价 / 每期交付物清单
都已从对外材料移除 —— 它们对个人创作者不成立，写出来只会增加误解与维护义务。

## 五、一次跑完你会拿到什么

| 文件 | 内容 |
|---|---|
| `final.mp4` | 1080p30 · h264 + aac · loudnorm −14 LUFS |
| `index.html` | 确定性单文件渲染源，同 `t` 同像素，可重渲任意时间段 |
| `SCENE-PLAN.json` | 场景、字幕、旁白、音效卡点的机器契约 |
| `qa.json` | 11 项评分 + 病灶时间戳 |
| `pipeline_report.json` | 阶段耗时 / 退出码 / 产物清单 / 失败阶段 |
| `final_audio.wav` + 分轨 | BGM / SFX / 旁白分轨 |

## 六、质量与边界

- 硬门禁 `avg < 8 → exit 1`，不允许带病出片；调阈值必须跑回归夹具与实片同帧对比。
- 只做 1920×1080 横屏；竖屏实测后主动放弃，不写成「后续支持」。
- 不换 Remotion / Motion Canvas 等第二渲染路径（引擎不是瓶颈，`docs/11`）。
- 工程链路端到端测过；方法论里部分禁令来自观察而非严格 A/B，文档如实标注。

## 七、数据与成本

- 全链路本地运行：无遥测、无账号、无外部数据回传；产物只写本地项目目录。
- 模型 API Key 由使用者自持；`scripts/env*.ps1` 里的 token 永远是占位符（`SECURITY.md`）。
- 依赖均为开源或系统组件（numpy / pillow / edge-tts / Chrome / ffmpeg）；
  不需要付费连接器，也不需要 GPU。
- 素材与成片版权归使用者；我们不托管、不复用、不用于训练。

## 八、常见问题

1. **要花多少钱？** ¥0。MIT 开源、自托管，没有订阅费或按量收费。
2. **我不会写代码能用吗？** 目前需要命令行：`python scripts/verify.py` 验收、
   `run_all.ps1` 出片。没有图形界面，这一点不包装成「零门槛」。
3. **需要独立显卡吗？** 不需要。旁白走 edge-tts，画面靠无头 Chrome CDP 抓帧。
4. **能换模型吗？** 能。渲染 / QA / 音频 / 合成模型无关，`SCENE-PLAN.json` 是纯 JSON 契约。
5. **能改片长和输入吗？** 能，同一条主链支持一句话 / 论文 PDF / 仓库 README 与 8–180s。
6. **支持竖屏吗？** 不支持，只做 1920×1080 横屏。

## 九、文案同步纪律

`site/index.html` 是本文档与 README 双语的**摘要**：改一处必须三处同步。
站点页脚不写死版本号，避免多一处同步负担。
