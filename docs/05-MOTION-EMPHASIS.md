# 动效与强调规范（v2 · 固定机位）

> 本轮改写的起因：**"镜头不要抖动，只拍正面全屏"**。
> 之前我用相机推拉/漂移来制造动感，结果被感知为"抖"。这一版把规则反过来：
> **机位锁死，动感全部来自页面元素与背景本身。**

来源与依据：

| 来源 | 拿来什么 |
|---|---|
| [claude-motion-playbook](https://github.com/PHY041/claude-motion-playbook)（233 条 Opus 5.5 动效片、137 个技巧的统计研究） | ① 最好的规格都有同一套骨架：`<inputs><direction><structure><build><gotchas><start>`；② **"同一个提示词会产出不同的片"——所以多抽几版留最好的是唯一可控杠杆**；③ 盲评显示"加油式措辞"（go all out）不加分，**钱花在 gotchas 和确定性渲染、QA 闸门上** |
| [vibe-knowledge-video 的 prompt-brief](https://github.com/xiazhuo123456789/vibe-knowledge-video/blob/main/references/prompt-brief.md) | XML 框架的字段划分、五区布局、双语规范 |
| [HyperFrames Prompt Guide](https://hyperframes.heygen.com/guides/prompting) | "提示词扩展"思路：把一句话扩成逐场景可执行规格（含 blur/缓动/时长具体值） |

## 一、机位规则（硬性）

```
1. 机位固定：全片不做推镜、不做摇移、不做缩放漂移。
   cam() 恒返回 {s:1, dx:0, dy:0}。
2. 动感来源改为三层：
   L1 背景层：每章一套背景 + 自身持续运动（漂移/扫光/呼吸）
   L2 元素层：进场/退场/位移/缩放/描边
   L3 强调层：放大、闪烁、抖动、冲击（见第三节）
3. 允许"元素抖动"，禁止"整幅画面抖动"。
   区别：抖动的是这个数字/这个词，不是镜头。
```

> 一句话：**镜头是三脚架上的，动的是画面里的东西。**

## 二、背景：一章一套（禁止全片同一背景）

每章必须有**可辨识的底色 + 一种专属纹理 + 它自己的运动**：

| 章 | 底色 | 专属纹理 | 持续运动 |
|---|---|---|---|
| 概率 | 深蓝黑 `#0A0A18` | 点阵 | 点缓慢上浮 + 单点游走 |
| 相遇 | 紫蓝 `#141026` | 两道斜光束 | 光束横扫（8s 一周期） |
| 最优停止 | 墨青 `#0A1418` | 斜网格 | 网格平移 |
| 失效 | 暗红棕 `#1A0C0A` | 碎屑 | 碎屑下落 + 闪烁 |
| 长期 | 深海军蓝 `#0A1020` | 同心圆 | 圆环缓慢扩张 |
| 依恋 | 暖灰紫 `#161018` | 柔光斑 | 呼吸式明暗 |
| 落点 | 金黑 `#140E06` | 光晕 | 脉动 |

**判定标准**：把七个章节的静帧并排看，**不看字幕也能分出是哪一章**。分不出就是没做到。

## 三、强调：四个动作，各有用途

| 动作 | 参数 | 用在哪 | 不要用在 |
|---|---|---|---|
| **放大冲击** `punch` | 1.0 → 1.14 → 1.0，0.36s，`easeOutBack` | 关键数字落地（2.7%、37%、5:1、56%） | 普通字幕 |
| **闪烁** `flash` | 白色遮罩 0.18 → 0，2 帧；同时元素亮度 ±25% | 章节切换、结论砸下 | 连续两次以上（会累） |
| **元素抖动** `shake` | ±7px，横向为主，0.22s，3 次衰减 | 否定/打叉/错误结论 | 正向信息 |
| **描边 + 色彩注入** | 描边 2px 金色，填充由灰变金，0.3s | 关键词升级（"37%"→金色） | 整段文字 |

**节奏**：一个强调动作前后各留 0.4 秒安静，否则观众分不清哪个是重点。
**上限**：全片强调点 ≤ 8 个。超过 8 个等于没有重点。

## 四、信息层级（一帧只有一个主角）

```
一级：当前数字 / 当前结论（字号 ≥ 90px 或 全屏 1/4 面积）
二级：支撑图形（网格/曲线/天平/卡片）
三级：注释（25px，灰）
四级：顶栏、时间码（21px，更灰）
```

**规则**：同一帧里，**只有一个元素允许发光**。第二个发光的东西出现时，第一个必须退光。

## 五、与旧版的三处冲突（已作废）

| 旧版 | 新版 | 原因 |
|---|---|---|
| 相机推 8.5%、漂移 150px | **机位固定** | 被感知为抖动 |
| 全片单一深蓝背景 | **一章一套背景** | 分不清章节 |
| 靠"密度 ≥0.3%"衡量动感 | 密度只作参考，**主判据改为"静帧辨识度 + 强调点数量"** | 相机推拉能刷高密度却不产生"强调感" |

## 六、验收增补（qa_check 之外的人工项）

| 项 | 判据 |
|---|---|
| 静帧辨识度 | 7 章静帧并排，不看字幕能分出 5 章以上 |
| 强调点 | 全片 3–8 个，每个前后各 0.4s 安静 |
| 一帧一主角 | 任意随机 5 帧，每帧只有一个发光元素 |
| 机位 | 全片 `cam()` 恒定；任意两帧的画面外框完全重合 |
