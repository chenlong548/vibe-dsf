# 25 · 后续升级计划（计划项，不影响当前发布）

> **这份文件是路线图，不是待办清单，也不是当前版本的完成度说明。**
> 当前版本功能完整、可独立发布，判据见 `docs/24-MVP.md`（`python scripts/verify.py` → 9/9 PASS）。
> 下面每一条都是「以后可做」的可选增强，**没有一条是发布前置条件**：
> 不进 `scripts/verify.py`、不进 CI 必过项、不进 `docs/23` 发布清单的必选检查、不阻塞打 tag。

## 一、计划项的准入规则

1. 先写清「改哪个文件、验证哪条指标」，再动手；不改变 `render(t)` 纯时间函数与 `SCENE-PLAN.json` 契约。
2. 在独立分支做，合回主链前必须通过 `python scripts/verify.py` 与至少一条实片 QA 过闸。
3. 新增能力默认先进「可选扩展」区（`docs/24` 第四节），只有被日常出片真正依赖时才纳入发布面。
4. 每次合入按 SemVer 递增版本：`VERSION` + `CHANGELOG.md` + 双语 README 版本行 + 附注 tag。
5. **计划项失败或被否决，直接标注结论即可，不影响当前版本继续发布。**
