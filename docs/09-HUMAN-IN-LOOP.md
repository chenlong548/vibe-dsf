# 人工介入流程（Human-in-the-loop）

> 你说得对：现在这套流程太"全自动"了。文案、分镜、场景、每帧提示词——**都是创作决策，
> 不该由模型一次拍板**。这一版把流程改成七个闸门，每个闸门前都有交付物、有审核点。

## 一、七道闸门

```
① 基础信息  →  ② 文案  →  ③ 分镜  →  ④ 场景描述  →  ⑤ 每帧提示词
        →  ⑥ 2D / 2.5D / 3D 选择 + 素材  →  ⑦ 生成与验收
```

| 闸 | 谁做 | 交付物 | 人工必须确认什么 |
|---|---|---|---|
| **① 信息** | 人 | 主题 / 观众要记住的一句话 / 时长 / 受众平台 | — |
| **② 文案** | AI 起草，**人改** | `script.md`：每句带时间码、中英双语 | **逐句念一遍**，别扭的删掉 |
| **③ 分镜** | AI 起草，**人改** | `storyboard.md`：每镜的时间/画面/动作/转场 | 节奏是否够快、转场是否"有劲" |
| **④ 场景描述** | AI | 每镜一段 50 字画面描述（谁、在哪、什么在动） | 有没有画不出来的东西 |
| **⑤ 每帧提示词** | AI | 每镜一条实现提示词（含参数、缓动、禁止项） | 参数是否与风格包冲突 |
| **⑥ 形式与素材** | **人决定** | 2D / 2.5D / 3D 标记；可提供图片/logo/实拍 | **这一条不许 AI 自己决定** |
| **⑦ 生成** | AI + 脚本 | 帧序列 → MP4 + QA 报告 | 看片，标秒数 |

## 二、两条硬规则

**规则 1：⑥ 之前不许写代码。**
以前我是"边想边写"，结果文案一改，2000 行全废。现在必须先过 ⑥。

**规则 2：人工提供的素材优先于 AI 生成。**
logo、产品图、实拍空镜、手写稿扫描件——**人给的素材一律直接进画面**，
AI 只负责排版、动效、光影统一。提示词里写：

```
素材清单（人工提供，不得替换、不得重绘）：
  assets/logo.svg       → 出现在 3.2s 与 18.6s，最大宽度 320px
  assets/photo-01.jpg   → 作为 12–20s 的背景，需压暗 40% + 轻微推近
其余图形由代码绘制。
```

## 三、节奏模板（"快剪"预设）

你说当前太"平缓"，这是参数问题，不是审美问题。三档预设：

| 档 | 单镜时长 | 硬切间隔 | 转场方式 | 适合 |
|---|---|---|---|---|
| 慢（旧默认） | 15–25s | 30s+ | 交叉淡化 | 纪录片、情绪片 |
| **中（新默认）** | **6–10s** | **8–12s** | **3 帧白闪 + 1.06 放大冲击** | 知识片、讲解 |
| 快 | 3–5s | 4–6s | 硬切 + 0.12s 方向性模糊 | 预告、卡点 |

**"震撼感"的三个来源**（都写进提示词）：
1. **骤停**：切之前 0.3 秒把音乐/画面压到静音或黑场 2 帧
2. **过冲**：切之后的元素用 `easeOutBack` 进场，过冲 6%，再回位
3. **方向一致**：切进来的元素与上一镜的退出方向相反（上一镜向右飞走，这一镜从左冲入）

## 四、文字层级（你提的"文字在最上层、不许堆叠"）

**层级（从下到上）**：
```
背景 → 环境光 → 场景图形 → 暗角 → 【字幕/注释/顶栏】 → 白闪
```
- 字幕与顶栏**永远在暗角之上**（否则会被压暗）
- 白闪是唯一的"盖住文字"的层，且只持续 3 帧

**防堆叠的三条**：
1. **安全区**：所有画面元素的最低点 ≤ `y=800`；字幕带 `y=880–960` 不许放任何其他东西
2. **占位检查**：渲染前跑一次 `qa_check.py --overlap`，列出文字包围盒相交的帧
3. **一帧一个焦点**：同一帧只允许一个元素发光，第二个出现时第一个退光
