## 二、差距：七个真实短板（按致命程度排序）

### G1 · 画面信息密度不足 = "PPT 味"（最致命）

亲眼验证（film-love-math 60s 版静帧）：
- **29s 天平镜头**：全画面只有一条横线 + 两个小方块 + 一行字幕，**约 80% 是空黑**
- **44s 心形镜头**：一条曲线居中，无层次、无第二视觉元素
- 对比基准："高密度扑面而来"。差距不是"难看"，是"**空**"

根因：flash 按最省事方式写代码，一个主体 + 字幕就交差。禁令 F1 只管"不难看"，不管"满"。
**修法 → 任务 #5：四层构图模板**，把密度变成可抄的骨架 + 可验收的数字（死黑占比）。

### G2 · QA 门禁形同虚设

`film-love-math/qa.json` 实测：**总分 7.14 < 8.0 交付线，仍然出了片**。
- 静止段 **49 个**（最长 4.47s），静止控制 4/10
- **首帧抓人 0.07%** 密度 vs 全片 0.81% —— 开头 4 秒画面几乎不动，钩子完全失败
- 36 次硬切（切点节奏 5/10）

根因：闸门靠人自觉，没有硬卡点。**修法 → 任务 #3/#4：QA 加退出码 + 流水线自动拦截。**

### G3 · QA 只测"动没动"，不测"好不好看"

当前 7 项全是运动/切点/字幕带指标。以下全部测不出来：
画面空不空（死黑占比）、构图居中对称（F1 违规）、有没有强调色焦点、暗部糊成一团。
**修法 → 任务 #3：新增 4 个审美维度。**

### G4 · 渲染太慢，迭代不动 = 质量封顶

每帧起一个 Chrome 进程：0.54s/帧。180s 片 = 5400 帧 ≈ **50 分钟/轮**。
改一处文案重渲几分钟起步——**迭代速度是质量的前提**，慢就没人愿意改第三轮。
**修法 → 任务 #2：CDP 长连接复用浏览器，预期 3–8 倍。**

### G5 · 构图全面居中对称（违反自家 F1 禁令）

看的 3 帧全部左右对称、主体居中。flash 的对称癖写在禁令里，但禁令是软约束——
没有模板和验收数字，它每次都滑回去。**修法：G1 的模板 + G3 的重心检测双保险。**

### G6 · 无音效层（SFX），MV 感缺一半

`synth_bgm.py` 只有 BGM。比特新语式观感的一半来自 **whoosh / impact / UI 音效贴着动效走**
（数字砸下配 impact、卡片飞入配 whoosh）。CUE-SHEET 已经有卡点表，正好逐点铺音效。
**修法 → P1：synth_sfx.py 按卡点表合成音效轨，与 BGM 混音。**
**✅ 已修（2026-11-06，P1 #6）：`pipeline/audio/synth_sfx.py` 落地，6 音效白名单 +
riser 向前铺 + SFX 不闪避，见 docs/17-SFX.md；demo-hook-compound 三层音频端到端首验通过。**

### G7 · 没有品牌资产，流程没有编排

- 水印还是 `@YOURNAME` 占位符——账号品牌、片头模板、片尾署名卡没有沉淀成资产
- 5 条命令人肉跑，闸门靠自觉——现在是"自动化零件、人肉流水线"
- **修法 → 任务 #4 一键流水线；P1 品牌参数（palette.json + 水印字）进每条片契约**
