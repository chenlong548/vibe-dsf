# 风格 DNA（数值规范 · 直接抄，不要自己发明）

> 这些数字不是审美偏好，是**逆向 8 条爆款 + 逐帧统计**得到的。
> DeepSeek 的自由发挥会把它变回"PPT 味"，所以：**照抄数值，只改内容。**
> **本项目只做横屏。**竖屏需要重写坐标系统，已在 2026-10-22 明确放弃。

## 1. 技术规格

| 项 | 值 |
|---|---|
| 分辨率 | **1920×1080（只做横屏）** |
| 帧率 | 30fps（4K 用 60） |
| 时长 | 90–180 秒，中位 ~135 秒 |
| 编码 | H.264 + AAC 44.1kHz，−14 LUFS |
| 音轨 | 器乐 BGM 76–78 BPM；有旁白时 BGM 自动闪避 −9dB |

## 2. 五区布局（y 按 1080 高）

```
y=40–80    左上 @作者水印        中上 章节标签          右上 时间码 mm:ss:ff   ← 全片恒定
y=270–740  中央主视觉区（占画面 30%–65%）
y≈790      画面注释（一行小字，解释当前动画）
y≈890      字幕中文主句（46px 粗体）
y≈940      字幕英文斜体（27px，Georgia italic）
```

恒定性：水印/标签/时间码**全片不许移动**——这是"系列感"的来源。

## 3. 配色

| 用途 | 色值 |
|---|---|
| 背景 | `#05050F` → `#12122A` 径向渐变（中心亮、四周暗） |
| 主文字 | `#EAEAF2` |
| 强调（只用一个） | 金 `#C9A96A` 或 暖橙 `#E8A87C` |
| 辅助灰 | `#8A8AA0`（注释、英文小字） |
| 纸张 | `#EDE4D3`（卡片/文献） |
| 印章红 | `#B53A2F` |

叠加层：极淡星点（170 个，alpha 0.18–0.52）+ 静态颗粒（900 个 1.5px 点，alpha 0.012–0.04）+ 暗角（径向，边缘 −62%）。

## 4. 字体（白名单）

| 用途 | 字体 | 字号 |
|---|---|---|
| 中文标题 | 衬线 900（SimSun / Noto Serif SC） | 76–100px |
| 中文正文 | 黑体 700（Microsoft YaHei / PingFang SC） | 46px |
| 画面注释 | 黑体 400 | 25px |
| 英文引文 | Georgia italic | 25–27px |
| 大写标签 | 无衬线 + **字距 0.25–0.3em** | 20–21px |
| 数据/时间码 | 等宽 Consolas | 21–22px |

> 字距是"高级感"最便宜的一招：`tracked("VIBE", x, y, 6)`。

## 5. 节奏

| 项 | 数值 |
|---|---|
| 字幕 | 每句 2.5–4 秒，中文 ≤20 字 |
| 画面密度 | 每帧 ≥0.3% 像素在变；相邻 2 秒必须有可见变化 |
| 静止 | 单处 ≤4 秒；全片断点 ≤4 处 |
| 缓动 | 全部 easeInOut / 弹簧；进场可用 easeOutBack（过冲 ≤6%） |
| 硬切 | 全片 2–6 次；其余靠元素变形过渡 |
| 强调 | 关键词描边/变色/放大 1.05×；数字滚动计数 |

## 6. 转场（必须从内容长出来）

| 好 | 坏 |
|---|---|
| 一条线延伸成坐标轴 | 淡入淡出 |
| 卡片飞散重组 | 黑场 |
| 曲线末端变地平线 | 圆形遮罩 |
| 网格放大成地图 | 平移推镜 |
| 数字滚动变成章节号 | 白闪 |

## 7. 声音

- BGM：76–78 BPM，小调，4/4；低音 pad + 柱式和弦 + 轻打击
- 段落：钩子段只有 pad → 推演段进和弦 → 转折加琶音 → 结尾回落
- 响度 −14 LUFS，峰值 −1.5dB，无爆音
- `synth_bgm.py` 已实现以上全部，改 `--bpm` 和段落比例即可

## 8. 三张必过的静帧

| 帧 | 检查点 |
|---|---|
| 开场钩子 | 前 2 秒有元素进场吗？悬念够不够？ |
| 机制高潮 | 信息密度堆到最高了吗？有没有"看不懂"？ |
| 结尾卡 | 有引用/署名吗？最后一帧不是空的吧？ |
