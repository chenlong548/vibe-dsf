# 多层构图模板（layer templates）—— 消灭"PPT 味"的骨架

> 谁该读：写 index.html 之前的每一个人（包括 flash）。
> 解决什么：G1 差距——画面只有"1 个元素 + 字幕"，80% 是空的。
> 比特新语的观感是"高密度扑面而来"，这个文档把"密度"翻译成**四层骨架 + 密度预算 + 可验收数字**。
> 配套验收：`qa_check.py v2` 的「画面充实」（中央内容占比，爆款线 ≥12%）
> 和「构图偏置」（重心 0.42–0.46 或 0.54–0.58）两项就是按这套模板定的阈值。

---

## 一、四层骨架（z 轴从低到高，绘制顺序 = 编号顺序）

每一帧都必须有 L0 和 L2；L1、L3 在"信息镜头"里必须有，在"情绪镜头"里可减。

### L0 氛围层（全屏，永远在动）

| 项 | 参数 | 说明 |
|---|---|---|
| 底色 | 双色径向渐变，中心比边缘亮 25–40% | 例 `#12122A → #05050F`；**禁止纯黑 #000** |
| 专属纹理 | 每章一种：点阵 / 斜网格 / 同心圆 / 斜光束 / 碎屑 | alpha 0.04–0.10，占屏 100% |
| 颗粒 | 900 个 1–2px 静态点，固定种子 | alpha 0.012–0.04 |
| 暗角 | 径向，边缘 −55~−65% | 文字画在暗角**之上** |
| 自身运动 | 纹理漂移/呼吸/扫光，周期 6–12s | 每帧贡献 0.05–0.15% 像素变化 |

```js
// 骨架：L0 一段式
function drawL0(t, pal){          // pal = 本章配色（底色/纹理/强调色）
  paintRadial(pal.bgIn, pal.bgOut);
  paintPattern(pal.pattern, t);   // 纹理随 t 缓慢漂移
  paintGrain(SEED);               // 固定种子，不闪
  paintVignette(0.62);
}
```

### L1 支撑层（画面的"骨架感"，占屏 30–60%）

| 项 | 参数 | 说明 |
|---|---|---|
| 结构图形 | 网格 / 轨道线 / 坐标轴 / 卡片阵列 / 关系连线 | 亮度 = 主视觉的 25–40% |
| 进场 | 生长式（线延伸、圆扩张、格浮现），easeOut 0.8–1.2s | **禁止整层淡入** |
| 数量 | 1–2 组，多了变乱 | 与主体有从属关系，不许纯装饰 |

```js
function drawL1(t){
  // 例：从主体重心生长的同心刻度圆
  const g = easeOut(clamp01((t - t0) / 1.1));   // 生长进度
  for (let i = 1; i <= 5; i++){
    const r = i * 130 * g;
    strokeCircle(cx, cy, r, `rgba(201,169,106,${0.10 + i * 0.015})`);
  }
}
```

### L2 主体层（一帧一个主角，占屏 ≥12% 或字高 ≥120px）

| 项 | 参数 | 说明 |
|---|---|---|
| 面积 | 主视觉占画面 **≥ 12%**（数字/曲线/核心图形） | 低于 12% = QA「画面充实」必挂 |
| 重心 | 偏离中线 **8–15%**（x = 0.42–0.46 或 0.54–0.58） | F1 硬规则，QA 会测 |
| 发光 | 全帧**只许一个**发光元素 | 第二个出现时第一个退光 |
| 强调色 | 只染主角（描边/填充/发光），L1 永远不染 | 保证焦点唯一 |

### L3 标注层（专业感的来源，2–4 处）

| 项 | 参数 |
|---|---|
| 数据标注 | 单位 / 来源 / 刻度值 / 指向箭头，21–25px，辅助灰 |
| 顶栏 | 水印 / 章节标签 / 时间码，全片位置恒定 |
| 规则 | 标注必须有信息量（说得出"删了会丢什么"才留） |

```js
function drawL3(t){
  note(`S = k·log W`, x1, y1, MONO, 24);        // 公式
  note(`Boltzmann · 1877`, x2, y2, SANS, 21);    // 来源
  note(`↑ 扩散不可逆`, x3, y3, SANS, 22);        // 指向
}
```

## 二、密度预算表（写完自查，QA 数字对不上就返工）

| 层 | 贡献（中央内容占比） | 缺失时 QA 表现 |
|---|---|---|
| L0 纹理+颗粒 | 1–3% | 「画面充实」3/10，画面像纯色板 |
| L1 支撑图形 | +4–8% | 画面"空而稳"，PPT 味 |
| L2 主体 | +5–10% | 重心采不到（com_x = -1），「构图偏置」5/10 |
| L3 标注 | +1–3% | 专业感塌掉，字幕占用 <1% |
| **合计目标** | **≥ 12%（爆款线）/ ≥ 18%（满分线）** | v2 QA 的「画面充实」10 分制 |

**画布分配（1920×1080）**：
```
y=40–80     L3 顶栏（恒定）
y=120–820   L0 全部 + L1 主体区 + L2 主视觉（重心 x=805 或 1115±40）
y=840–790   L3 画面注释
y=880–960   字幕带（中文 46px + 英文 27px italic）
```

## 三、组装顺序（一个镜头的标准写法）

```js
window.render = (t) => {
  const pal  = chapterPalette(t);   // 一章一套配色
  const prog = sceneProgress(t);    // 本镜进度 0→1（内部全走 ease）
  drawL0(t, pal);                   // 1. 氛围
  drawL1(prog, pal);                // 2. 支撑（生长式进场）
  drawL2(prog, pal);                // 3. 主体（唯一发光）
  drawL3(prog, pal);                // 4. 标注
  drawSubtitle(t);                  // 5. 字幕（暗角之上）
  drawTopbar(t);                    // 6. 顶栏（恒定）
};
```

**三条反模式（写之前再看一眼）**：
1. ❌ 主体居中 + 四周全空 —— 就是 flash 的默认输出，模板存在的意义就是干掉它
2. ❌ L1 用纯装饰（和主体无关的花纹）—— 支撑层必须"解释主体的语境"
3. ❌ 每层都加运动 —— L3 标注必须静止（恒定感），动的只有 L0/L1/L2

**L1 笔画宽度备忘（QA 实测教训，熵增 Demo 8.5 分的失分点）**：
`qa_check v2` 的「画面充实」用纹理能量（局部标准差）计——**1px 细线几乎测不出来**。
熵增 Demo 的 5 圈同心圆全是 1.2px 描边，纹理能量只有 9%。结论：
- L1 结构线 **≥ 2px**，或者用双线/填充面（带状、色块化）
- L2 主体优先用**有面积**的形状（粒子云、色块、粗描边数字），别只用细线稿
- 「画面充实」要上 9 分（≥11%），画面里必须有 2–3 个"有面积"的元素

## 四、验收对照

| QA v2 指标 | 模板对应 | 目标 |
|---|---|---|
| 画面充实 ≥12% | L1+L2+L3 的密度预算 | 骨架照抄即可达标 |
| 构图偏置 0.42–0.46 / 0.54–0.58 | L2 重心规则 | 主体进场就偏置 |
| 强调焦点 0.3–3% | L2 只染主角 | 粒子/曲线/数字带强调色 |
| 一帧一发光 | L2 发光规则 | grep `shadowBlur` 每帧 ≤1 处生效 |
