> 适用：心理 / 行为 / 博弈 / 社会现象（"为什么人会这样"类选题）
> 气质：绘本、剪纸、轻讽。**最适合把抽象机制演成一个小故事。**
> 画幅：**1920×1080 横屏**（竖屏已放弃）

## 一句话配方

米黄纸底 + 剪纸小人 + 手绘箭头 + 一本正经的旁白，演一件荒诞的小事。

## 配色

```
背景      #F3EBDD（米黄纸底，全片唯一浅底风格）
纸纹      rgba(120,100,70,.05) 噪点
剪纸人    深墨 #2E2A26，描边 3px
强调色    朱红 #C2452E（唯一）
次强调    藏青 #2F4858
手写标注  #6B5B48
```

> 注意：这是唯一**浅底**风格。所有"深底才好看"的发光/金色规则在这里全部失效——
> 换成"纸纹 + 阴影 + 手绘感"。

## 视觉母题

1. **剪纸小人**：圆头 + 梯形身体 + 两条腿，只用 5 个形状，深墨描边
2. **手绘箭头**：略带弧度的贝塞尔，粗细不均（模拟马克笔）
3. **纸片堆叠**：每出现一个新概念，加一张微微歪的纸质标签
4. **舞台框**：四周留一圈纸边（8%），像"在纸上演出"
5. **荒诞道具**：一个不成比例的物体（巨大的奖牌、很小的门）——这是笑点
6. **旁白气泡**：不是字幕，是画在画面里的纸条，带折角

## 动效签名

- 小人进场：从纸边"滑进来"，停住时轻微晃两下（`easeOutBack` + 阻尼正弦）
- 纸片：落下时旋转 2–4° 回弹一次
- 箭头：沿路径"画"出来（分段绘制），0.4–0.6 秒
- 转场：把整张"纸"往上抽走，露出下一张纸（不是淡入淡出）
- 节奏：比 A/B 两包都慢——每句旁白 3.5–4.5 秒，留呼吸

## 可直接粘进提示词的风格块

```
画风：剪纸绘本。米黄纸底 #F3EBDD + 极淡纸纹噪点，四周留 8% 纸边像舞台框。
人物是 5 个形状拼的剪纸小人，深墨描边 3px。唯一强调色朱红 #C2452E。
所有标注用手绘感的箭头和带折角的纸片，不要用 UI 组件。
动效要有"纸的物理感"：落下带轻微回弹和 2–4° 旋转，进场滑入后晃两下。
```

## 别踩的坑

- 在浅底上用发光 → 立刻脏；改用"投影 + 描边"
- 小人画得太精细 → 失去剪纸感；5 个形状就是上限
- 字幕不要压到画面最底部 → 横屏下会贴边难看；放 83% 处，底部留 10% 空白
- 幽默感靠"比例失衡"，不靠表情包
