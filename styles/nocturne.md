# 风格包 B · 深空理性（nocturne）

> 适用：物理 / 数学 / 算法 / 统计 / 信息论 / 系统
> 气质：实验室、坐标系、冷静、精确。**最容易做出"高级感"也最容易做成 PPT 的一类。**
> 建议画幅：**横屏 1920×1080**（本项目只做横屏，竖屏已放弃）

## 一句话配方

纯黑底 + 极细坐标轴 + 一条会生长的曲线 + 等宽数字 + 一个发光点。

## 配色

```
背景      #000000 → #0A0A14（几乎纯黑，比纸金更冷）
网格线    rgba(255,255,255,.08)  1px
坐标轴    rgba(255,255,255,.20)  1.4px
曲线      青白 #C8E6F5（唯一强调色，替代金色）
关键点    #F5E4BE（暖白，只给"结论点"）
数字      #FFFFFF 等宽
注释      #6E6E85
```

## 字体与字号

| 元素 | 规范 |
|---|---|
| 公式/符号 | 衬线斜体 Georgia，64–96px |
| 数字 | Consolas 等宽，直接给到 120–200px（数字是主角） |
| 轴标签 | 22px 黑体，灰 |
| 中文讲解 | 40px 黑体，白 |

## 视觉母题

1. **坐标轴生长**：x 轴从左到右 0→1 秒长出，y 轴同步；永远先轴后线
2. **曲线生长**：260 段折线，`easeInOut` 1.8–2.2 秒长完，带 24px 同色发光
3. **移动发光点**：点在曲线上走，带垂直虚线投影到 x 轴
4. **参数卡片**：右上角小卡片，实时显示当前参数（"成功率 37.4%"）
5. **万人网格**：28×N 个小格子，随机点亮——表现"大量重复实验"
6. **对比条**：两条水平条长度差 = 结论，数字放条尾

## 动效签名

- 轴：描边自绘（`stroke-dashoffset` 思路，用分段绘制模拟）
- 曲线：从起点连续 `lineTo`，禁止"整条淡入"
- 点：用 `shadowBlur 26` 让它"发光"，但**全片只此一处发光**
- 数字：滚到目标值后停 0.4 秒再切走（给观众读的时间）

## 可直接粘进提示词的风格块

```
画风：深空理性。近纯黑背景（#000→#0A0A14），极细白色网格（alpha .08）与坐标轴（alpha .20）。
唯一强调色是青白 #C8E6F5，只给曲线；暖白 #F5E4BE 只给"结论点"。
数据用等宽字体放到 120px 以上，公式用衬线斜体。先画轴、再长线、最后放点。
全片只有一处发光（当前焦点），其余全部哑光。
```

## 别踩的坑

- 网格太亮 → 变"工程图"；alpha 别超过 0.1
- 曲线整条淡入 → 一眼假；必须"生长"
- 同时亮 3 个以上元素 → 观众不知道看哪；一帧只有一个焦点
- 数字不加单位/不加来源 → 显得像编的
