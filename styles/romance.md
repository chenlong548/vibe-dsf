# 风格包 D · 落日暖调（romance）

> 状态：**已出验证帧**（`projects/romance-demo/`，5.6 秒那张），未出全片。
> 适用：爱情 / 亲情 / 怀念 / 遗憾 / 成长（一切"情绪 > 信息"的选题）
> 气质：旧胶片、逆光、尘埃、欲言又止。**和纸金风的区别：纸金是"证据"，这套是"体温"。**

## 一句话配方

暖棕底 + 一道斜射窗光 + 散景光斑 + 浮尘 + 一张米白纸条（微旋，楷体手写）+ 中文单语大字幕。

## 配色

| 用途 | 色值 |
|---|---|
| 背景（右下暗） | `#120806` → `#22110C` → `#3A1F14` 径向 |
| 逆光光晕 | `rgba(255,206,150,.30)` 中心衰减到 0 |
| 斜射窗光 | `rgba(255,196,140,.13)` → 透明 |
| 散景光斑 | `255,214,160` / `255,182,120`，alpha 0.10–0.26 |
| 浮尘 | `#FFE3BE`，alpha 0.15–0.50 |
| 纸 | `#FFF9EC` → `#F7EBD5` → `#EBDCC0` |
| 纸边暖光 | `rgba(255,226,180,.55)` 1.6px |
| 墨（手写） | `#3A2A22`，落款 `#6B5240` |
| 字幕 | `#F6ECD8` |
| **唯一强调色** | 暖金 `#E0B87A`（只用于顶部标签、时间码、纸边光） |

## 字体

| 元素 | 规范 |
|---|---|
| 手写内容（信、纸条、批注） | **楷体**（KaiTi / STKaiti）62px，字距自然 |
| 中文字幕 | 黑体 700，**52px**（中文单语可放大，比双语版多 6px） |
| 顶部标签 | 黑体 500，21px，**字距 3px** |
| 片名卡 | 衬线 900，86px，暖金 |

> **本片一律中文，不用英文斜体小字。**理由：情绪片里英文会把观众推出戏。

## 动效签名（慢是核心）

| 动作 | 参数 |
|---|---|
| 纸条入场 | `easeOutBack`，缩放 0.94→1.0，旋转 −4°，时长 1.1 秒 |
| 纸条静止 | 极慢摆动：`sin(t*0.5)*0.35°`（几乎看不出来，但能感到"活着"） |
| 手写字 | 逐字浮现，每字 60–90ms，带 0.12 秒淡入 |
| 浮尘 | 上下正弦 ±10px，周期 8–15 秒，亮度呼吸 |
| 光斑 | 上下漂 ±14px，周期 20 秒以上 |
| 字幕 | 淡入 0.5 秒 + 上移 8px；**停留 3.5–4.5 秒**（比知识片慢） |
| 转场 | 光晕过曝 0.3 秒 → 下一镜淡入；或纸边滑出画面 |

**禁止**：快切、弹跳、粒子爆炸、数字滚动——这套风格里它们都会破坏情绪。

## 声音

- BGM：**66–70 BPM**（比知识片慢 10），钢琴单音 + 弦乐 pad
- 织体：钩子段只有单音钢琴 → 中段进 pad → 转折处留 1 秒静默 → 结尾回到单音
- 混音：−14 LUFS，但**允许整体比知识片低 2dB**（情绪片不需要响）

## 可直接粘进提示词的风格块

```
画风：落日暖调。暖棕径向底（#120806 边角 → #3A1F14 中心），一道斜射窗光带，
16 个暖色散景光斑（alpha .10–.26）缓慢上浮，70 粒浮尘呼吸，微弱暖色胶片颗粒，暖调暗角。
唯一强调色是暖金 #E0B87A，只给标签、时间码、纸边光。
所有文字一律中文，不用英文；字幕 52px 黑体，停留 3.5–4.5 秒。
手写内容用楷体，逐字浮现。动效全部慢速：纸条入场 1.1 秒、极慢摆动 ±0.35°。
禁止快切、弹跳、粒子爆炸。
```

## 别踩的坑

- 光斑 alpha 超过 0.3 → 变"梦幻滤镜"，廉价
- 楷体用在标题上 → 像喜帖；标题仍用衬线，楷体只给"手写的东西"
- 底色太亮 → 失去"旧"；最深角别高于 `#3A1F14`
- 情绪片配快节奏 BGM → 全毁，宁可慢到 66BPM
