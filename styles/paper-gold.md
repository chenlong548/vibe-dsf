# 风格包 A · 纸金双语（paper-gold）

> 适用：哲学 / 社科 / 反直觉心理 / 诺贝尔奖故事
> 气质：纪录片、旧纸、印章、克制。**最像比特新语那一类片子的底子。**
> 已完成样片：`projects/demo-26s/`（26 秒，可直接跑）

## 一句话配方

深空蓝黑底 + 一张做旧米白纸卡 + 金色衬线标题 + 红色中文印章 + 双语字幕。

## 配色

```
背景渐变  #05050F → #12122A
主文字    #EAEAF2
金（唯一强调色） #C9A96A
纸张      #EDE4D3
纸上的字  #2A2A38 / #5C5C6E
印章红    #B53A2F
辅助灰    #8A8AA0
```

## 字体与字号

| 元素 | 规范 |
|---|---|
| 片名 | 衬线 900，86–100px，金色，带 40px 金色外发光 |
| 章节标签 | 21px 无衬线，字距 0.28em，金色 |
| 画面注释 | 25px 黑体，灰色，居中在 y≈790 |
| 中文字幕 | 46px 黑体 700，白，y≈890 |
| 英文字幕 | 27px Georgia italic，#9C9CB4，y≈940 |

## 视觉母题（按出场顺序）

1. **金色细线生长**：开场从中心向两侧延伸 560px，1.2px 粗 —— 全片的"引子"
2. **纸卡**：330×150，圆角 6，微旋转 −3°，`shadowBlur 40`
3. **红印章**：80×46 描边 3px，旋转 +8°，盖在纸卡右下角
4. **双语字幕带**：中文主句 + 英文斜体小字，永远成对出现
5. **金色虚线**：用于"测量/对应关系"，`setLineDash([3,6])`
6. **数字滚动**：关键数字用 `lerp` 从 0 滚到目标值，200ms

## 动效签名

- 标题：`easeOut` 淡入 + 上移 14px，40px 金色发光
- 纸卡：`easeOut` 上浮 20px 入场，微旋转从 −5° 到 −3°
- 细线：宽度从 0 长到 560px，`easeOut` 1.15 秒
- 退场：只降 alpha，不位移（纸质感的东西不该"飞走"）

## 可直接粘进提示词的风格块

```
画风：深空蓝黑纪录片。背景 #05050F→#12122A 径向渐变 + 极淡星点 + 静态颗粒 + 暗角。
唯一强调色是金 #C9A96A，只出现在深色背景上。标题用衬线 900 金色，正文用黑体。
凡需要"证据感"的地方，用一张做旧米白纸卡（#EDE4D3，微旋转 -3°，投影）配红色中文印章。
主视觉重心偏离中线 10%。全片不用第二个强调色。
```

## 别踩的坑

- 纸卡不要做圆角超过 8px（会变"卡片 UI"而不是"纸"）
- 印章不要居中，一定偏在角落
- 金色一旦用在浅底上，立刻变脏 → 浅底换深棕 #5C4A2A
