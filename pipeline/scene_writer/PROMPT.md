# PROMPT · 万能场景规划任务书（模型无关）

> **给谁用**：任何 LLM。WorkBuddy 02、DeepSeek-Flash、强模型皆可——把本文件全文塞给模型，附上一行输入即可。
> **解决什么**：作者没时间"把每个场景写清晰"。本任务书把 layer-templates.md 的设计纪律全部编译成
> 生成时的硬约束 + 自查清单，模型吐出的 SCENE-PLAN.json 直接过 `validate_plan.py` 硬闸。
> **人的角色退化为**：给主题 → 看过闸成片 → 说"行/不行"。

---

## 输入格式（一行即可）

```
主题：<一句话>
时长：<秒数，可省略 → 默认 8-12s 钩子片>
BPM：<可省略 → 默认 126>
参考：<可省略，如"参考熵增 demo 的配色">
```

## 你（模型）的任务

产出**一个完整的 SCENE-PLAN.json**（契约见 `SCENE-PLAN.schema.md`，必须严格符合）。
不写 index.html，不写渲染代码——那是 build_html.mjs + blocks 积木的事。

---

## 第一步：叙事设计（先想清楚再填数字）

用五段叙事组织场景（时长 <12s 可只写 hook，或 hook+land）：

| 段位 | 目标 | 手法 | 字幕语气 |
|---|---|---|---|
| `hook` 0-20% | 3 秒内制造认知缺口 | 提问 / 反常识画面 / 巨大反差 | 疑问句，punch 感 |
| `anchor` 20-45% | 给一个可抓住的具体物 | 一个数字 / 一个形象 / 一个公式 | 陈述，短 |
| `reason` 45-70% | 展开机制 | 曲线 / 分叉 / 计数爆走 | 因果句 |
| `turn` 70-85% | 反转或加深 | 对撞 / 换视角 | 转折词开头 |
| `land` 85-100% | 金句落点 + 记忆锚 | 定格 / 双数字对撞 | 格言式，punch=true |

**字幕 = 旁白 = 观众听到的**。中文一句 ≤ 18 字（46px 字幕带宽度限制），配英文意译。
每条字幕必须完整落在某个场景内。

## 第二步：从 blocks 积木库选型（禁止凭空发明画面）

只准用 registry 里注册的积木，按"段位 → 积木"直觉选：

- 爆点 / 能量释放 / 冲击 → `entropy-burst`
- 对比 / 增长 / 趋势 → `data-chart`（自带坐标轴，l1 可省）
- 数字锚 / 公式 / 计数 → `beat-counter`
- 对撞 / 双结局 / 反转落点 → `vs-counters`

多场景可用同一积木换参数（换重心位置/换窗口时间），但相邻场景禁止完全相同构图。

## 第三步：硬约束（校验器会逐条挂你，先自查）

1. **时间轴**：scenes 无缝覆盖 [0, duration]；边界全对齐拍点（60/bpm 的整数倍，±0.5 帧）；
   beats 和 sfx.t 同样对齐。duration 本身 = 拍点整数倍。
2. **L2 主体**：每场景必须有；`area_pct ≥ 0.12`；重心 `cx ∈ [0.40,0.46] ∪ [0.54,0.60]`——
   **禁止居中 0.5**。params 里带 `area_pct`（按积木说明估）。
3. **L1 支撑**：要用就 `stroke ≥ 2`（1px 细线 QA 测不出，实测教训）；生长式进场，
   窗口 0.8-1.2s，写在场景内。
4. **L3 标注**：时长 ≥2.5s 的场景 ≥2 条（单位/来源/指向/刻度），font 20-26px，color=gray；
   必须有信息量——说不出"删了丢什么"的不要写。
5. **密度预算**：est = area_pct + (l1?0.05:0) + l3条数×0.012 + 0.02 ≥ 0.12，冲 0.18。
6. **发光唯一**：每场景 glow_window ≤ 1 个。
7. **配色**：bg_out 禁纯黑；accent 全片唯一且饱和度足够（s≥0.25, v≥0.35）；L1/L3 永不染强调色。
8. **sfx**：name 只能是 impact-low / impact-mid / tick / riser / sub-drop / whoosh。
9. **确定性**：所有随机性靠 params.seed；一切窗口时间用绝对秒。

## 第四步：输出前自查清单（逐条过，打勾才准输出）

- [ ] duration、所有边界、beats、sfx.t 都在拍点网格上（自己乘一遍 60/bpm）
- [ ] 每个 scene 的 l2.block 在注册表里
- [ ] 每个 cx 不是 0.5，且在允许区间
- [ ] 每个 ≥2.5s 的场景有 ≥2 条 l3
- [ ] 字幕一条不跨场景、互不重叠、中文 ≤18 字
- [ ] 五段非降序；≥12s 时 ≥3 个不同段位
- [ ] 全片只有一个 accent 色值

## 输出格式

只输出一个 JSON 代码块（SCENE-PLAN.json 全文），不要额外解释。
若被 validate_plan.py 打回：**只修正列出的违规项，其余保持不动**，重新输出完整 JSON。
